# CyberGuard

**AI-Native Cybersecurity Built for Africa.** *One Platform. Zero Blind Spots.*

The marketing and onboarding frontend for CyberGuard: product, platform, solutions,
industries, pricing and resources pages, plus demo booking, trial sign-up and login flows.

## Getting started

```bash
npm install
npm run dev        # http://localhost:3000
```

| Script | What it does |
|---|---|
| `npm run dev` | Start the dev server |
| `npm run build` | Production build |
| `npm run start` | Serve the production build |
| `npm run lint` | Lint with ESLint |
| `npm run typecheck` | Type-check without emitting |

## Pages

`/` · `/products` · `/platform` · `/solutions` · `/industries` · `/pricing` · `/resources`
· `/about` · `/contact` · `/book-demo` · `/start-trial` · `/signup` · `/login`

## Tech stack

Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui (Radix UI), Framer Motion,
React Hook Form + Zod, Recharts.
